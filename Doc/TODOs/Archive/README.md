Status note:

- this directory stores completed phase TODO files grouped by phase range
- active phase files should remain in `Doc/TODOs/`
- when a phase is completed, verified, and documented, move it into the matching `by-phase/` bucket

Purpose:

- keep the top-level archive readable after hundreds of completed slices
- preserve completed phase evidence without deleting or zipping history
- make `docs:check` able to find the latest completed slice recursively
