AI 使用儀表板是一個小小的 AI 編碼配額駕駛艙：配額、設定阻塞、同步健康狀態，都放在同一個地方。

打開 Chrome 工具列彈窗，先快速瞄一眼；需要細節時，再進入側邊欄或完整頁面儀表板。少翻幾個頁面，多寫幾行程式。(^_^)

它支援 Codex、Cursor、Claude Code、Gemini Code Assist 等編碼工作流程，並清楚標出每個來源是精確值、部分資訊、使用視窗、政策說明，或暫時不可用。

它不要求你貼上 cookie，也不要求你貼上原始瀏覽器 auth header。設定、可選 API 憑證、頁面綁定、快取快照、匯入匯出檔案和 Chrome Sync 資料都保存在你的 Chrome 設定檔中。

它能幫你看到什麼

• provider 健康狀態與設定阻塞項目
• provider 暴露時的剩餘使用視窗與重設時間
• 來源類型：API、已登入頁面、部分頁面上下文、文件政策或不可用來源
• 快照新鮮度與同步狀態
• 工具列標記與工具列圖示行為
• 語言、主題、popup 外觀、進度樣式、provider 順序與匯入匯出設定

日常使用時，它想解決什麼

AI 編碼助手很好用，但配額頁、帳號狀態和權限問題很容易讓人霧煞煞：剛才還能跑，下一秒可能就遇到額度視窗、權限缺失、登入工作階段過期，或某個 provider 的配額策略變了。

AI 使用儀表板想做的，就是把這些狀態收進一個安靜的小面板裡。你可以先快速瞄一眼，真的需要時再展開細節。一個小儀表板，不是又一個要管理的專案。✨

Provider 覆蓋會如實標示

不同 provider 暴露的資訊不一樣：

• 有些路徑可以顯示即時或接近即時的使用視窗
• 有些路徑只能顯示部分頁面上下文
• 有些路徑在目前版本只是政策說明
• 有些 provider 可能需要已登入頁面、可選 host access 或 API 憑證
• 各家 dashboard、API、配額文字和政策都可能改變

當某個來源不可用或只能提供部分資訊時，擴充功能會標出這個狀態，而不是編造一個數字。

隱私和權限

AI 使用儀表板採用保守設計：

• 不要求貼上 cookie
• 不要求貼上原始瀏覽器 auth header
• 可選主機權限只用於支援的 provider 來源
• favicon 權限只用於可選的「工具列圖示匹配 provider」功能
• 只執行打包腳本，不載入遠端程式碼
• 設定和快取資料保存在 Chrome 設定檔中，除非你主動匯出

這不是 OpenAI、Cursor、Anthropic、Google、JetBrains 或其他 provider 的官方產品。
