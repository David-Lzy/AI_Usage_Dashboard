## English

New in 0.2.1: a refreshed icon and clearer Settings with Quick Setup first.
Optional quota/reset notifications, period summaries, sanitized diagnostics,
CSV export, and saved Sub2API deployment comparison make usage easier to review.
An opt-in Codex CLI Companion can read quota without refreshing a browser tab.
Its API-equivalent estimate needs sufficient complete local observations and is
not a subscription bill or balance.
