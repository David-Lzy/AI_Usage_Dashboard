AI 使用仪表盘 - 给 AI 编码配额一个清清楚楚的小驾驶舱 ✨

AI 编码助手很好用，也很容易让人一头雾水：刚才还能跑，下一秒可能就遇到额度窗口、权限缺失、登录会话过期，或者某个 provider 的配额策略变了。

AI 使用仪表盘想解决的就是这件事：把这些状态收进一个 Chrome 工具栏 popup 和侧边栏仪表板里。你可以先快速瞄一眼，再进入侧边栏看细节。少翻几个页面，多写几行代码。(^-^)

它能帮你看到什么

🟢 provider 暴露出来的使用窗口和剩余额度百分比
🕒 支持路径里的重置时间
🧭 设置阻塞项，例如缺少主机访问权限、缺少凭据、页面未登录
🧩 数据来源类型：官方 API、已登录页面会话，或文档化策略
🧾 明确的支持边界：能精确就说精确，只是部分信息就标为部分信息
🔄 同步健康状态和快照新鲜度，需要你处理时会明确提示

它是怎么工作的

AI 使用仪表盘会根据不同 provider 使用不同的数据来源：

• Codex 可以从已登录的 Codex 使用页面读取可见的使用窗口百分比和重置时间；如果你配置了 Enterprise analytics，也可以使用对应路径。
• Cursor 可以使用 Team Admin API，或者使用已登录的个人 dashboard 页面读取计费周期相关的使用上下文。Cursor 个人页面目前不暴露一个精确的“剩余 included requests”计数，所以扩展不会假装它有。
• Claude Code 当前支持 Admin Analytics API 路径，或已登录的 Claude Team usage page；不会声称能给出精确的订阅内剩余额度。
• Gemini Code Assist 在当前版本中是 policy-only，也就是展示文档化策略，不声称有稳定的个人实时用量来源。

重点是：每张 provider 卡片都会告诉你它正在使用哪种来源。这个值是精确、部分、窗口级、策略级，还是暂时不可用，界面都会尽量说清楚。

为什么有工具栏 popup

popup 负责快速判断：

• 现在有没有健康的 provider？
• 有没有东西被权限或凭据卡住？
• 哪个 provider 需要关注？
• 当前扩展图标上的 badge 表示什么？

它故意做得比较轻。需要深入查看时，可以打开侧边栏里的仪表板、设置、provider 详情、来源合同和同步状态，不把所有东西都硬塞进一个小 popup 里。

为什么有侧边栏

侧边栏是主要工作区：

• 在一个仪表板里查看所有 provider 卡片
• 查看详细的使用窗口和重置时间
• 调整同步间隔、告警阈值、badge 显示、语言、主题和 popup 外观
• 给支持的 provider 页面授予或检查主机访问权限
• 绑定已登录的使用页面，不需要导出 cookie，也不需要手动粘贴 auth header

它不是一个一次性欢迎页，而是一个可以反复打开、反复检查的小控制台。

隐私和数据边界

AI 使用仪表盘的策略比较保守：

✅ 不要求你粘贴 cookie。
✅ 不要求你粘贴浏览器里的原始 auth header。
✅ 扩展设置、可选 API 凭据、页面绑定和缓存快照保存在当前 Chrome 用户配置中。
✅ 只对支持的 provider 来源请求可选主机权限。
✅ 页面读取逻辑使用随扩展打包的脚本，不加载或执行远程代码。

当使用已登录 provider 页面时，扩展会在你授权对应主机访问权限后，从当前浏览器会话中读取页面可见的用量信息。如果页面未登录、不可读，或者页面结构已经变到无法解析，仪表盘会显示这个状态，而不是编一个数字出来。

它不是什么

这不是 OpenAI、Cursor、Anthropic、Google、JetBrains 或其他 provider 的官方产品。

它也不是账单系统、发票系统，或者 provider 限额的最终裁判。各家 provider 可能调整 dashboard、API、配额策略和文字说明。遇到这种变化时，AI 使用仪表盘的目标是清楚地显示异常，而不是悄悄猜测。

它也不声称覆盖所有 AI 编码工具的完整实时用量。有些 provider 能给精确值，有些只能给使用窗口上下文，有些在当前版本里只是 policy-only。这个扩展会把这些差异摆在明面上。

适合谁

☕ 同时使用多个 AI 编码工具的人
📌 不想每天手动打开好几个用量页面的人
🧠 想知道一个数字到底是精确、部分，还是只是策略说明的人
🛠 希望权限或凭据出问题时能看到下一步提示的人
🔍 关心额度、重置时间和同步状态的人

最后一点点

AI 使用仪表盘不是想把用量管理变得更神秘，而是想让它更清楚。一个小 popup，一个侧边栏，一些诚实标签，再加上能跳到正确页面的操作入口。目标很简单：少一点猜，多一点确定。✨
