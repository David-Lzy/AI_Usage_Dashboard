Document class:

- maintained reference

- maintained copy for 0.2.2; not proof of Store submission or publication

These notes describe 0.2.2 only. Store submission and publication are separate;

## English

New in 0.2.2: a unified, compact Material-style interface across Settings,
Dashboard, side panel, Provider details and Popup. Settings now has five clear
categories with responsive navigation, retained drafts and confirmed save/retry
feedback. Choose Default, Follow system, More or Reduced motion. Fixes include
animation selection, keyboard activation and right-to-left menu placement.

## Simplified Chinese

0.2.2 更新：统一设置、仪表板、侧栏、Provider 详情与 Popup 的简洁 Material 风格。
设置重新归为五类，支持响应式导航、保留输入草稿及真实保存／重试反馈。
动画提供默认、根据系统、更多、减少四档；修复动画选择回跳、键盘操作与 RTL 菜单定位。
已有设置、Provider 数据含义与权限保持不变。

## Traditional Chinese

設定重新分為五類，支援響應式導覽、保留輸入草稿及真實儲存／重試回饋。
動畫提供預設、依系統、更多、減少四種模式；修正動畫選擇、鍵盤操作與 RTL 選單定位。
既有設定、Provider 資料意義與權限維持不變。
