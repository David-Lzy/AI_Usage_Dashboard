## en

Title: AI Usage Dashboard

Short description: Track usage, setup blockers, and sync health across AI coding tools.

Overview: Get a quick popup summary of visible AI tools, see the next setup step when access or credentials are missing, and open the side panel for deeper provider and contract review.

Feature bullets:
- Quick glance in one click: see visible providers, live-ready paths, setup blockers, and policy-only coverage without opening a separate dashboard.
- Clear setup guidance: when a provider needs host access, credentials, a signed-in page, or a reload, the popup points to the next action.
- Honest provider coverage: source chips distinguish official APIs, logged-in session pages, and documented quota-policy fallbacks.
- Settings and provider detail live in the side panel, with visibility controls, credentials, permissions, and source contracts kept together.
- Real extension-mode screenshots are captured from the built Chrome extension, not from a mocked marketing page.

Screenshot captions:
- Main dashboard: Review visible providers, quota state, and source health in one side panel.
- Popup quick glance: Open the toolbar popup for a compact provider summary and the next setup step.
- Setup guidance: Follow focused actions when host access, credentials, or a signed-in usage page are missing.
- Settings controls: Manage visibility, credentials, permissions, appearance, and source preferences in one place.
- Provider detail: Inspect source contracts, diagnostics, usage windows, and reset context for each provider.
